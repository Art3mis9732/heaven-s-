# For Heaven

A one-page apology site for Heaven: a handwritten-style letter, a garden of roses, peonies and cherry blossoms, and a gift table of ice cream, cheesecake and chocolate cake to unwrap.

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from the `main` branch) to get a link.

Photos are from [Unsplash](https://unsplash.com) and are stored in `images/`.
